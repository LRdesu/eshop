### 3.1 `orders` 关键字段（金额口径）
```
goods_amount      商品行金额合计
discount_amount   优惠金额（券）
shipping_fee      运费
pay_amount        实付 = goods_amount - discount_amount + shipping_fee
pay_status        0未付 1已付 2已关闭(超时)
order_status      0待付款 1待发货 2已发货 3已签收 4已完成 5已取消
expire_at         支付截止时间（默认 30 分钟）
paid_at / confirmed_at / auto_confirm_at
```

### 3.2 `order_items` 关键字段（分摊口径）
```
price            下单时单价快照
quantity         数量
goods_amount     行金额 = price * quantity
discount_amount  该行分摊到的优惠额（券分摊）
pay_amount       该行实付 = goods_amount - discount_amount
```

## 4. 关键业务规则（防坑定义）

### 4.1 优惠券叠加互斥规则（用户点名最易出 bug 处）
**采用确定性、可推导的规则，杜绝组合歧义：**

| 券类型 | 维度 | 互斥规则 |
|--------|------|----------|
| `FULL` 满减券 | 商品 | 一个订单**最多 1 张** |
| `DISCOUNT` 折扣券 | 商品 | 与 `FULL` **互斥**，二者取其一；同类最多 1 张 |
| `SHIPPING` 运费券 | 运费 | 一个订单**最多 1 张**，且**可与上述商品券叠加** |

即：**商品维度 ≤ 1 张 + 运费维度 ≤ 1 张**，跨维度可叠加，同维度绝不叠加。
券可用性还须同时通过：有效期、使用门槛（满 X 减 Y）、适用范围（全场/分类/指定商品）、持有且未使用。
**前后端同规则校验**：前端据此置灰不可选券，后端再校验一次（不信前端）。

### 4.2 优惠分摊算法（决定退款金额）
```
订单优惠额 discount 分摊到各行：
  item.discount = round(order_discount * item.goods_amount / Σgoods_amount, 2)
  尾差（几分钱）补到金额最大的那一行，保证 Σitem.discount == order.discount
```
使用 `Decimal` 计算，**绝不使用 float**。

### 4.3 退款口径（用户点名重点）
```
退款金额 = round(item.pay_amount / item.quantity * refund_qty, 2)
```
**按实付分摊比例退，绝非按原价 `goods_amount` 退。**
- 部分退款：不退运费
- 全部退款且使用了运费券：运费券失效，运费一并退
- 退款成功后**回补库存** `sku.stock += qty`

### 4.4 支付幂等与超时关单
- 支付单 `payment_no` 唯一；**幂等键 = payment_no + 目标状态**
- 重复 SUCCESS 回调：直接返回成功，**不重复加积分 / 不重复扣款 / 不重复发货**
- 已 SUCCESS 后再收到失败回调：**忽略**，状态不可回退
- 超时关单：查询订单/支付单时**惰性检查** `expire_at < now 且未支付` → 关单 + 释放库存 + 券状态回滚（`CLOSED`）

### 4.5 履约与自动收货
- 商家发货 → 生成 `shipments` + 运单号 → 写 `shipment_traces` 轨迹（已揽收/运输中/派送/签收）
- 签收后进入待确认，超过自动确认时限 → 查询惰性触发 `order_status=4 已完成`

### 4.6 RFM 分层
- **R** 最近一次下单距今天数 / **F** 累计订单数 / **M** 累计实付金额
- 分层标签写入 `user_tags`：如 `重要价值客户` / `重要保持客户` / `一般发展` / `流失挽留` / `新客`

## 5. 接口清单（按 9 步流程）

| 步骤 | 接口 |
|------|------|
| 注册登录 | `POST /api/v1/auth/register` `POST /api/v1/auth/login` |
| 选品决策 | `GET /api/v1/products` `GET /api/v1/products/{id}` `GET /api/v1/reviews?sku_id=` |
| 加购 | `GET/POST /api/v1/cart` `PATCH /api/v1/cart/{id}` `DELETE /api/v1/cart/{id}` |
| 结算 | `POST /api/v1/orders/preview`（预估价/可用券/运费） `POST /api/v1/orders`（下单锁库存） |
| 支付 | `POST /api/v1/payments`（生成支付单） `POST /api/v1/payments/{no}/pay`（模拟付款） `POST /api/v1/payments/callback`（**幂等**回调） |
| 履约 | `POST /api/v1/shipments/{order_id}/ship`（发货） `GET /api/v1/shipments/{id}/traces` |
| 收货 | `POST /api/v1/orders/{id}/confirm`（确认收货） |
| 售后 | `POST /api/v1/aftersales` `GET /api/v1/aftersales` `POST /api/v1/aftersales/{id}/refund`（比例退款+回补库存） |
| 评价 | `POST /api/v1/reviews` |
| 复购 | `GET /api/v1/members/me`（积分+RFM标签） `POST /api/v1/members/rfm/refresh` |
